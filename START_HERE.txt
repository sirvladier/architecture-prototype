ПЕРЕНОС И ЗАПУСК НА ДРУГОМ КОМПЬЮТЕРЕ (WINDOWS)

1. Распакуйте архив целиком в любую удобную папку.
2. Установите Python 3.12, если его ещё нет.
3. Откройте PowerShell в распакованной папке, где находится app.py.
4. Один раз выполните:

   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt

   Для установки библиотек нужен интернет.

5. Запускайте приложение командой:

   .\.venv\Scripts\python.exe -m streamlit run app.py

6. Откройте в браузере:

   http://127.0.0.1:8501

Окно PowerShell оставьте открытым, пока пользуетесь приложением.
Для остановки нажмите Ctrl+C в этом окне.
Если порт 8501 занят, добавьте к команде запуска --server.port 8502
и откройте http://127.0.0.1:8502.

ПРОВЕРКИ

Тесты:
   .\.venv\Scripts\python.exe -m pytest -q

Технический эксперимент:
   .\.venv\Scripts\python.exe -m src.experiment

Результаты эксперимента создаются в папке data.

В архив входят код, конфигурации, синтетические кейсы, тесты и документация.
Локальный Python, виртуальное окружение, кэши, журналы и старые результаты
не включены. Оценки архитектур и остальные содержательные параметры модели
сохранены без изменений. Все они остаются PLACEHOLDER / MODEL VALUES.

Подробное описание: README.md.
