ПЕРЕНОС И ЗАПУСК НА ДРУГОМ КОМПЬЮТЕРЕ (WINDOWS)

1. Склонируйте репозиторий или скачайте актуальный исходный код с GitHub.
2. Установите Python 3.12.
3. Откройте PowerShell в папке с app.py и выполните один раз:

   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt

4. Запустите приложение:

   .\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8501

5. Откройте http://127.0.0.1:8501. Для остановки нажмите Ctrl+C.

В пользовательском режиме задаются значимость шести критериев и два обязательных
требования. Архитектурная матрица и правила рисков заданы конфигурацией.
Числовые оценки 1–5 — порядковая исследовательская модель, а не
универсальные нормативные характеристики архитектур.

ПРОВЕРКИ

Тесты: .\.venv\Scripts\python.exe -m pytest -q
Эксперимент: .\.venv\Scripts\python.exe -m src.experiment

Эксперимент создаёт CSV, JSON-результаты и снимок конфигурации в data.
Подробности и оговорка о стоимости K6: README.md.
